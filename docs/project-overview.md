# Project Overview

## Purpose

Project Atlas documents the physical restoration and modernization of a Dell Latitude E7250 into a reliable Ubuntu infrastructure server.

The project demonstrates how an older business-class laptop can be assessed, repaired, upgraded, and validated as a dependable server platform.

## Objectives

- Extend the useful life of existing hardware.
- Upgrade memory from 8 GB to 16 GB DDR3L.
- Retain and validate the Samsung 256 GB M.2 2242 SATA SSD.
- Improve cooling and long-term reliability.
- Restore worn physical components in planned phases.
- Provide local maintenance access while using SSH routinely.
- Document decisions, evidence, testing, and lessons learned.

## Scope

This repository includes hardware assessment, memory installation, storage validation, cooling improvements, physical repairs, local console hardware, wired-network hardware selection, benchmarks, temperatures, stability testing, and sanitized evidence.

The broader homelab architecture and detailed service configurations are documented elsewhere. Athena may be trialed on Atlas later, but it is a possible workload rather than part of the restoration scope.

## Storage Direction

Atlas will retain its Samsung 256 GB M.2 2242 SATA SSD. A purchased WD Blue SA510 1 TB M.2 2280 SATA SSD was physically incompatible and was not installed.

A future capacity upgrade will be considered only when actual requirements justify a compatible M.2 2242 SATA drive or separate external storage.

## Method

Every modification will be planned, documented, tested, photographed when useful, sanitized before publication, and verified before the next stage.

## Current Status

The project is in the assessment and hardware-upgrade phase. The memory kit, cooling stand, and wireless keyboard have been purchased. Storage compatibility has been verified and the original SSD will remain in service.
